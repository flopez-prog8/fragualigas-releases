# FraguaLigas — Descargas

**La fragua de tus ligas.** Binarios oficiales de FraguaLigas para Android.

## Descargar

[Última versión](https://github.com/flopez-prog8/fragualigas-releases/releases/latest)

Capturas y detalles del proyecto: [fragualigas-showcase](https://github.com/flopez-prog8/fragualigas-showcase).

Cada release incluye el APK firmado y sus notas de versión. La app comprueba
`version.json` para avisar de actualizaciones.

## Versiones

- `versionCode` crece con cada release.
- `versionName` es la versión visible.
- `minVersionCodeSoportado` marca cuándo una actualización es obligatoria.
